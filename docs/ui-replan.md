# UI / 功能再規劃（MVP）

## 核心問題

- 分頁太多，使用者在旅行中不會想記很多入口。
- 很多表單只有展示，缺乏「現在該做什麼」的操作順序。

## 新資訊架構（4 分頁）

1. **總覽**：今天行程、下一個預訂、預算摘要、準備進度。
2. **行程**：機票/住宿/交通與每日時間軸放在同一頁。
3. **預算**：花費、分帳、當前超支提醒。
4. **準備**：行前清單 + 成員分工。

## 第一階段（本次已完成）

- Bottom Nav 從 6 分頁縮減到 4 分頁。
- 新增 `ItineraryPage` 合併「預訂 + 時間軸」。
- 新增 `PrepPage` 合併「準備 + 成員」。
- 保留現有 seed/mock 資料，先把 UX 路徑收斂。

## 第二階段（下一步）

- 每頁只留一個主要 CTA（例如新增花費、新增行程）。
- 把目前假表單改成可寫入本地儲存（localStorage）後再接 API。
- 針對手機單手操作優化按鈕位置與字級。
